# Stock Price Prediction
MSc project investigating machine learning for predicting stock price direction across ten anonymised stocks.
 
Models included: 
Logistic Regression, Random Forest, XGBoost, SVM

Random Forest was selected as the final model.

## Setup
Install dependencies through requirements.txt

## Running the project
To train and compare models:
    python train.py

To run the final prediction model:
    python prediction.py
